# Arduino Dev Container

A lightweight, reproducible development environment for building and programming Arduino projects using **VS Code Dev Containers, Docker, and Arduino CLI**.

The aim of this project is to keep the Arduino toolchain and development dependencies inside a container, providing a consistent development environment without requiring a full Arduino development stack to be installed directly on the host system.

The initial target board is the **Arduino Uno R3**.

## Supported Environments

The project is designed to work on systems capable of running Docker and VS Code Dev Containers.

Windows with WSL2 is supported.

## Documentation

Setup instructions, platform-specific configuration, architecture, USB/serial access, development workflow, and troubleshooting are documented separately.

Please read the [`/docs`](./docs) folder for full project documentation.

## Project Status

The project currently focuses on Arduino Uno R3 development and may be extended to support additional boards and development workflows in the future.
